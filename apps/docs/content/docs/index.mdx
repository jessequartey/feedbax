## GitHub and existing applications

[Connect GitHub](/docs/getting-started/github) covers the private D1 database, shared/self-hosted App service, pairing and matching development CLI. [Native workflow](/docs/guides/github-workflow) explains approved content and independent status/publication. Changelog remains Notion-only. Public GitHub issue content is visible immediately at its source.

Use the [feedback block](/docs/integrations/feedback-block) for product UI and [Connected handoff](/docs/guides/connected-profile) for verified identity. They are independent integrations; API keys and email equality are not Participant identity.

## What you own

You own the source, Worker, domain, provider resources, and operational choices. Feedbax Core 0.2 does not require a hosted Feedbax account.
