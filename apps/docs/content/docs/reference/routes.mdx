---
title: Routes
description: Public portal and documentation routes in Feedbax Core 0.2.
---

| Surface              | Route                                            |
| -------------------- | ------------------------------------------------ |
| Website              | `https://feedbax.dev`                            |
| Documentation        | `https://feedbax.dev/docs`                       |
| Documentation search | `GET https://feedbax.dev/api/search`             |
| Portal               | `https://feedback.feedbax.dev`                   |
| Trusted submission   | `POST https://feedback.feedbax.dev/api/v1/posts` |

Portal paths include the feedback feed, Roadmap, Changelog, Post detail, submission, and registry assets.
