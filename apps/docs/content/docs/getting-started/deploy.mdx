## Production secrets

The lifecycle deploy command uploads the Notion token, trusted API-key **hash**, participation signing secret, enabled Turnstile secret, and enabled Connected identity handoff secret after confirmation. The plaintext trusted API key belongs only in the calling product. Do not put secrets in `src/feedbax.ts` or `wrangler.jsonc`.

After deployment, verify the Worker preview hostname before attaching a custom domain.

Connected Installations also require their dedicated D1 binding and applied migration before deployment. Follow the [authentication guide](/docs/guides/connected-profile) and verify the real application handoff in a dedicated environment before enabling it for Participants.
