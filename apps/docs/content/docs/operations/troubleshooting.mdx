---
title: Troubleshooting
description: Diagnose common Notion, Worker, schema, and Participation failures.
---

## Notion content is missing

Confirm the database is shared with the integration and that the stable property IDs in `src/feedbax.ts` match the expected property types. Run `feedbax doctor`.

## Mutations fail in production

Check Worker secrets, rate-limit bindings, allowed origins, and the deployed Worker's logs. Reproduce first against the Worker preview hostname.

## Votes disappear

The Notion-only Profile stores Participation state in the browser. Clearing browser storage or switching browsers removes that local state. Changing or clearing the Device Profile alone does not grant or remove editing capabilities.
