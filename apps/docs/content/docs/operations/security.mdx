---
title: Security
description: Operate Feedbax without exposing secrets or sensitive workspace data.
---

- Keep Notion and trusted-submission secrets server-only.
- Publish only explicitly mapped properties.
- Apply rate limits to public mutations.
- Validate payloads and cap user-provided text.
- Review dependencies and Worker logs routinely.
- Do not place participant emails, private research, or API keys in docs or screenshots.

Report vulnerabilities through the repository [security policy](https://github.com/jessequartey/feedbax/blob/main/SECURITY.md).
