Votes are reversible and remembered in the current browser after server confirmation. Top orders by Vote Count and then creation time; New is chronological. Legacy Trending URLs resolve to Top. Different Worker instances can race when updating a count, and clearing browser storage removes local duplicate prevention.

A display name and valid contact email are required to create a Post, Comment, or reply. This Device Profile is unverified and stored on one browser. Comment names are public and marked unverified; email remains private and is never included in Comment content.

Comments and replies are native Notion discussions on Published Posts. Notion-authored contributions appear as Product Team. Resolving or deleting a discussion in Notion hides it from the portal. Detail pages load 50 Comments at a time; feed and roadmap cards do not fetch Comment counts.

The creating browser receives a signed Comment Capability for fifteen minutes. It can edit or delete that Comment during the window. Clearing storage, changing devices, or rotating the signing secret removes that access; there is no recovery. Participants cannot edit Product Team Comments.

All public writes are rate-limited. When Turnstile is enabled, the first successful participation challenge issues a Participation Pass for thirty minutes. See the [guarantees](/docs/reference/guarantees).

## Top focuses on unshipped feedback

Unfiltered Top excludes Shipped Posts so completed work does not occupy the highest-ranked feedback slots. Choose the Shipped status filter, search for a Post, use New, or open the roadmap to find completed work.
