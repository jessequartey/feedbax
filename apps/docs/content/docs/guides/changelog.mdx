description: Publish credible release notes from the same Notion workflow.
---

Changelog entries are feedback posts with release metadata. A useful entry says what changed, why it matters, and which feedback shaped it.

## Example release

### Feedbax Core 0.2

Core 0.2 adds public Comments, browser-scoped Votes, Roadmap views, Changelog publishing, trusted server submissions, and Cloudflare-first deployment checks.

Use a release date, stable slug, concise summary, and optional release notes URL. Only publish entries that are ready for Participants to read.
