Feedbax is a self-hosted feedback portal for Product Teams whose teams work in Notion or GitHub. Published 0.2.1 supports Notion; GitHub support is in 0.2.2.

## The model

```text
Participant → public Feedbax portal → selected Content Provider → Product Team
```

The portal handles public reading, submission, Votes, Comments, Roadmap, and Changelog. The selected provider remains the source of truth for triage and publication. GitHub uses a dedicated Feedback Repository and private operational D1; Changelog remains Notion-only.

## Core 0.2 boundaries

- One Installation, Product Team, product and selected Content Provider.
- Browser-held draft capabilities and unverified Device Profiles by default; optional Connected identity from your existing application. D1 alone is not verified identity.
- Cloudflare Worker deployment.
- No Feedbax-hosted identity, billing, or analytics service.

Read [Participation guarantees](/docs/reference/guarantees) before promising identity or voting properties to Participants.

The [GitHub guide](/docs/getting-started/github), [authentication guide](/docs/guides/connected-profile), and [feedback block guide](/docs/integrations/feedback-block) explain the independent setup paths. New Team Member tools remain deferred; native provider workflow is retained.
