---
title: Quickstart
description: Generate, configure, validate, and run a Notion-backed Feedbax portal.
---

## Prerequisites

- Node.js 22.18 or newer
- A Notion workspace and integration
- npm or pnpm

## Create a project

```sh
npx create-feedbax@latest my-feedback
cd my-feedback
```

Choose anonymous, email-only, or signed handoff identity. Email-only captures an unverified address; it does not authenticate ownership.

## Configure and validate

Copy `.env.example` to `.env`, set the documented server-only Notion and session values, then run:

```sh
npx feedbax doctor
```

Doctor reports blocking configuration, permissions, and schema failures with their owning extension. It never prints secret values.

## Run locally

```sh
pnpm install
pnpm dev
```

Use `npx feedbax add deploy cloudflare`, `vercel`, or `node` to select a verified deployment composition. Generated projects remain ordinary React, shadcn, Tailwind, and TypeScript source owned by their operator.
