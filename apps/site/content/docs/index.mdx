Feedbax is an open-source, bring-your-own-backend customer feedback portal. The first release is being designed for technical founders and small product teams that already run their workflow in Notion.

> **Pre-release:** the v0.1.0 product loop is implemented and automated release gates pass. Publication still waits on registry ownership, a live credential smoke test, and an independent quickstart.

## Read status before capability

Every claim in these docs uses one of four labels:

- **Available** — implemented and testable now.
- **Preview available** — implemented and covered by the repository release gates.
- **Release prerequisite** — complete only after an external launch gate is recorded.
- **Deferred** — intentionally outside the first release.

## Where to begin

Read [Product vision](/docs/product-vision) for the thesis, then review the [Quickstart](/docs/quickstart) to understand the intended installation path. The [Roadmap](/docs/roadmap) is the source for release scope.

## Current snapshot

**Preview available.** Feedbax generates a Notion-backed portal with anonymous, email-only, or signed-handoff identity. The portal includes submission, search, filters, duplicate suggestions, voting, comments, roadmap, changelog, accessible failure states, and verified Cloudflare, Vercel, and Node/Docker builds.

**Release prerequisite.** The npm names/scope must be secured, the opt-in live Notion smoke must pass with release credentials, and a non-maintainer must complete the quickstart before publication.
