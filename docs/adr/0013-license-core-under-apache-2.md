# License Core under Apache-2.0 without a CLA

Core uses Apache-2.0 and accepts contributions directly under the same license without a CLA or copyright assignment, while the future proprietary Cloud repository consumes exact released Core packages. This supersedes the planned AGPL/commercial dual-license model because direct no-CLA contributions do not provide the separate relicensing rights that model required; trademark, community, managed operation, and execution protect recognition and commercial value instead.
