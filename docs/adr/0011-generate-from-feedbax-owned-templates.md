# Generate from Feedbax-owned application templates

`create-feedbax` offers a guided experience inspired by Better-T-Stack but generates versioned, tested Feedbax-owned templates instead of invoking an independently changing scaffolder during installation. The first template uses TanStack Start only; additional frameworks require demonstrated demand or an outside maintainer, keeping identical CLI releases reproducible while preserving a future adapter path.
