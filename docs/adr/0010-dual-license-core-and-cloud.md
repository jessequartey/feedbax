# Dual-license Core and keep Cloud proprietary

Core is published under `AGPL-3.0-only`, while Feedbax Cloud uses Core under a separate commercial license and keeps hosted-only code proprietary. This protects access to modifications of network-deployed Core while preserving a path to integrated proprietary cloud capabilities; before outside contributions are accepted, a professionally reviewed contributor agreement must grant the commercial relicensing rights that repository separation alone cannot provide.
