# Offer two capability profiles

Feedbax provides a Notion-only Profile for zero-sidecar public browsing, submission, and status visibility, and a Connected Profile that adds the operational state needed for reliable identity and social interactions while keeping feedback content and planning in Notion. This preserves a genuinely lean quick start without misrepresenting browser-local data as authentication or weakening the reliability of voting, comments, following, and notifications.
